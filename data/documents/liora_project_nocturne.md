# เวชระเบียบลับปี 1923 — Project Nocturne

ในแฟ้มมีชื่อ ดร. ลิโอรา เวนน์ เชื่อมโยงกับ Project Nocturne และบันทึกทางการแพทย์เกี่ยวกับเหตุการณ์ปี 1923

เอกสารนี้ยืนยันความเกี่ยวข้องของเธอกับโครงการ แต่ยังไม่ใช่หลักฐานว่าเธอฆ่าแคสเซียน คุณควรสอบปากคำเธอเรื่องเวลาตาย และตรวจสอบว่าใครเป็นคนตัดไฟในคืนนี้

หากจะตรวจสอบที่อยู่ของเธอ ให้ตามหาบันทึกผู้ป่วยและพยานที่ตู้ 3: ตู้เสบียงและห้องพักพนักงาน
