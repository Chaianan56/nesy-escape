    ละเมิดกฎ           A 2 ครั้ง  |  B 0 ครั้ง  ← จุดที่ต่างจริง
    ตีความพลาด         A 1 ครั้ง  |  B 2 ครั้ง  ← มาจาก neural layer ซึ่งใช้ร่วมกัน

    เขียนถ้อยคำเอง     A 99% ของขั้น    |  B 0%

สิ่งที่ตัวเลขนี้บอกได้และบอกไม่ได้
    บอกได้    เมื่อ neural ตีความถูก symbolic ไม่เคยละเมิดกฎเลย ส่วน LLM ละเมิด
              และคำอธิบายของ symbolic มาจากกฎที่ถูกตรวจจริง ไม่ใช่ข้อความที่เขียนย้อนหลัง
    บอกไม่ได้ ว่า symbolic "แม่นกว่า" — อัตราถูกรวมเท่ากัน
              และหลักฐานเรื่องละเมิดกฎยืนอยู่บนกฎข้อเดียว (R014_TIME_LIMIT) เท่านั้น
              ซึ่งบางเกินกว่าจะสรุปอะไรได้
