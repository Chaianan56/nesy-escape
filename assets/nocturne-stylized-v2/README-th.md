# Nocturne Express · Stylized v2

ภาพชุดใหม่ 28 ภาพ: 8 ฉากหลัก, 14 ภาพตรวจหลักฐาน และ 6 ฉากจบ
ตัวละครและฉากเป็นงานภาพเกม Stylized 3D ใช้พื้นผิววาดมือ แสงเงาแบบ cel shading และรูปทรงการ์ตูน มุมมองผ่านสายตาผู้เล่น

เปิด `index.html` เพื่อดูแกลเลอรี กดภาพเพื่อเปิด PNG เต็มขนาด ทุกภาพมีพรอมป์ตใน `prompts/` และรายการเชื่อมกับหลักฐาน/คำให้การใน `catalog.json`

อ้างอิงเนื้อเรื่อง `../../data/story.json` โดยคงห้อง ตัวละคร และหลักฐานจากชุดเดิมไว้ ตู้ 1 แสดงทางเข้าเขตหวงห้ามเท่านั้น ฉากจบ unproven และ arrival เป็นกรณีพิเศษของระบบที่ระบุ canon: false

เกมไม่ได้กำหนดอาวุธผู้เล่น คีมเป็นหลักฐานการตัดไฟ รูปลักษณ์ตัวละครและของตกแต่งที่เรื่องไม่ได้ระบุเป็นการออกแบบภาพ

ตรวจภาพและเบาะแสสำคัญด้วยสายตาแล้ว รายละเอียดเล็กในภาพกว้างอาจไม่ตรงภาพขยายทุกพิกเซล ควรแสดงข้อความหลักฐานฉบับเต็มผ่าน UI ของเกมเพื่อให้อ่านได้ชัดเจน

สร้างด้วย built-in image_gen ภาพชุดนี้เชื่อมเข้าหน้าเกมแล้วผ่าน /game-art โดยแสดงตามคำสั่งที่ระบบอนุมัติ เก็บชุดเดิมไว้ที่ `../nocturne-v1/`
