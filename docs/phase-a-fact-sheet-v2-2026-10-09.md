# Nocturne Express — ระยะ A ฉบับที่ 2

วันที่ 9 ตุลาคม 2026 · ข้อกำหนดเนื้อเรื่องสำหรับพัฒนารุ่นถัดไป

เอกสารนี้จัดทำตามแผนที่ผู้ใช้ให้เริ่มดำเนินการ โดยตัดปมผู้โดยสารคนที่แปดออกและเลือกคำตอบให้ช่องว่างของเรื่อง เป็นข้อกำหนดงานเขียนฉบับใหม่ ไม่ใช่รายงานว่าข้อมูลหรือกฎในเกมถูกแก้แล้ว

ใช้คู่กับ [แผนดำเนินงาน](implementation-plan-2026-10-09.md) ส่วน [ระยะ A ฉบับแรก](phase-a-fact-sheet-2026-10-08.md) เก็บไว้เป็นบันทึกสภาพเกมก่อนเปลี่ยนเรื่อง

**เป้าหมายเพิ่มเติมจากผู้ใช้:** คดีต้องมีความซับซ้อนด้านเหตุผลเพื่อเปรียบเทียบ NeSy กับ neural-only และให้ผู้เล่นเข้าใจเรื่องผ่านการสืบสวน A2 กำหนดข้อเท็จจริง ส่วนการแปลงเป็นลำดับการค้นพบและสถานการณ์ทดสอบใน B ให้ใช้ [ข้อกำหนดความซับซ้อนและการประเมิน](design-goals-and-evaluation-2026-10-09.md) ร่วมด้วย การเก็บหลักฐานครบไม่ถือเป็นหลักฐานว่าผู้เล่นเข้าใจคดีแล้ว

## 1. ขอบเขตและแกนของเรื่อง

**ชื่อ:** Nocturne Express ใช้ชื่อหลักนี้โดยไม่มีชื่อรองระหว่างพัฒนา

**ประสบการณ์ที่ต้องการ:** ผู้เล่นจำสิ่งที่ตนเห็นได้ถูกต้อง แต่เกือบนำความทรงจำนั้นไปยืนยันข้อสรุปที่ผิด กิเดียนอยู่กับผู้เล่นตอนไฟดับจริง ทว่าการทำร้ายแคสเซียนเกิดก่อนหน้านั้น

**ประเด็นของเรื่อง:** การปิดคดีอย่างสะดวกเคยทำลายผู้คนมาแล้ว ผู้เล่นมีโอกาสหยุดการทำซ้ำด้วยการตรวจคำให้การกับหลักฐาน

ตัวละครในคดีคืนนี้ยังมีผู้ต้องสงสัยหลักสามคน ได้แก่ กิเดียน ลิโอรา และวินเซนต์ เพิ่มพนักงานตรวจตู้คนเดิมเป็นผู้ให้ข้อมูลที่กล่าวหาไม่ได้ ผู้ป่วยที่ลิโอรารักษาเป็นพยานที่มีอยู่แล้ว ตัวละครในคดีเก่าไม่กลายเป็นผู้ต้องสงสัยบนขบวนคืนนี้

ตัดประวัติคนที่แปด อาเดรียน การวางยาพิษในคดีเก่า และการตั้งใจทำให้รถชนเพื่อฆ่าบุคคลลับออกจากข้อกำหนดรุ่นนี้ คดีคืนนี้เป็นฆาตกรรมในห้องพักบนรถไฟ ไม่ใช้คำว่า “ห้องปิดตาย” เพราะไม่ได้มีกลไกห้องที่เข้าออกไม่ได้

## 2. ความจริงของคดีปี 1923

### 2.1 เหตุเบลล์เวเธอร์

คืนวันที่ **14 พฤศจิกายน 1923** ขบวนพิเศษ Nocturne อยู่ภายใต้การกำกับภารกิจของส่วนกลาง กิเดียน ฮาร์ตทำหน้าที่ผู้แทนฝ่ายกฎหมายและประสานคำสั่งของภารกิจ

แอนเซลม์ วอสส์ นายสถานีเบลล์เวเธอร์ แจ้งให้ขบวนหยุดรอการยืนยันว่าเส้นทางปลอดภัย กิเดียนใช้อำนาจกดดันให้ปล่อยขบวนต่อโดยอ้างความเร่งด่วนของภารกิจ การเดินรถต่อทั้งที่ยังมีคำเตือนนำไปสู่การชน

กิเดียนไม่ได้ตั้งใจให้เกิดการชน แต่หลังเกิดเหตุเขาเลือกปกปิดบทบาทของตน สั่งแยกโทรเลขเตือนและคำให้การที่กล่าวถึงคำสั่งส่วนกลางออกจากสำนวน รายงานที่เผยแพร่จึงอธิบายว่าเป็นอุบัติเหตุด้านการเดินรถ โดยไม่ระบุว่ามีคำสั่งฝืนคำเตือน

ความผิดที่แฟ้มเก่าจะเปิดเผยมีสองส่วนชัดเจน: **สั่งให้เดินรถต่อแม้ได้รับคำเตือน** และ **ใช้อำนาจตัดข้อมูลสำคัญออกจากการสอบสวน**

วันที่นี้ใช้เป็นวันเหตุฉบับใหม่ เอกสารโทรเลขรุ่นเก่าที่ลงวันที่ 15 พฤศจิกายนต้องแก้เมื่อย้ายเนื้อหาเข้าเกม ไม่ปล่อยให้มีวันที่สองชุด

### 2.2 เอเลียสและลิโอรา

เอเลียส เวนน์เป็นเจ้าหน้าที่ประสานงานประจำขบวนและเป็นผู้รอดชีวิต เขาได้รับรู้คำเตือนก่อนปล่อยรถและให้การถึงคำสั่งให้เดินต่อ คำให้การฉบับแรกถูกบันทึกระหว่างพักรักษาตัว แต่ต่อมาถูกตัดออกจากสำนวนและทำให้ดูไม่น่าเชื่อถือ

เอเลียสเสียชีวิตด้วยโรคประจำตัวในปี **1931** ขณะอยู่ในสถานบำบัด การเสียชีวิตครั้งนี้ไม่เปิดเป็นปริศนาฆาตกรรมอีกคดี

ลิโอราเก็บแฟ้มรักษาและสำเนาคำให้การของบิดาไว้ เธอต้องการให้คำพูดของพ่อกลับเข้าสู่สำนวน เอกสารของเธอพิสูจน์ว่ามีคำให้การขัดรายงานตั้งแต่ตอนนั้น ไม่ใช่เอกสารที่พิสูจน์รายละเอียดอุบัติเหตุหรือความรับผิดของกิเดียนได้ทั้งหมดเพียงชิ้นเดียว

ลิโอราไม่ไว้ใจแคสเซียนเต็มที่ เพราะเขาเคยลงนามปิดคดี แต่ยอมช่วยเมื่อเขาแสดงหลักฐานว่ากำลังส่งสำนวนเข้าสู่การตรวจสอบใหม่ ความลังเลของเธอคืนนี้มาจากการต้องพึ่งเจ้าหน้าที่ที่เคยทำให้ครอบครัวผิดหวัง และความกลัวว่าพยานหลักฐานจะถูกปิดอีกครั้ง

### 2.3 แคสเซียน มารา และการรื้อคดี

แคสเซียน รีดเป็นผู้สอบสวนที่เคยยอมลงนามปิดคดีภายใต้แรงกดดัน เขารู้ว่าข้อมูลถูกตัดออก แต่ตอนนั้นไม่กล้าต่อต้าน

ในปี 1938 มารา วอสส์พบสำเนาโทรเลขและสมุดบันทึกต้นฉบับของแอนเซลม์ผู้เป็นบิดา จึงให้แคสเซียนยืมตรวจเพื่อรื้อคดี แคสเซียนนำเอกสารนี้มาเทียบกับสารบัญราชการและคำให้การเก่าที่ลิโอราเก็บไว้ จนเชื่อมคำสั่งกิเดียนกับการปกปิดได้

ความขัดแย้งระหว่างมารากับแคสเซียนเกิดจาก **ใครควรถือสมุดต้นฉบับของบิดาในแฟ้ม B** แคสเซียนตัดสินใจจะส่งสมุดนั้นพร้อมสำนวนให้ผู้สืบสวนจากสำนักงานอัยการ แต่มารายอมให้ยืมตรวจเท่านั้นและขอคืน เธอเชื่อว่าการเก็บต้นฉบับไว้กับตนปลอดภัยกว่า เมื่อแคสเซียนยังยืนยันจะส่งสำนวน เธอจึงจ้างวินเซนต์ให้เอากระเป๋าที่บรรจุสมุดคืนก่อนถูกส่งลงจากขบวนที่เวสต์มาร์ช วินเซนต์รับงานให้นำคืนจากผู้ถือกระเป๋าบนรถ ไม่ว่าจะยังเป็นแคสเซียนหรือเปลี่ยนเป็นผู้รับสำนวนแล้ว

มาราจ้างให้ขโมยเอกสาร ไม่ได้จ้างให้ทำร้ายใคร และไม่ได้กำหนดวิธีทำไฟดับ เธอไม่อยู่บนขบวนคืนนี้ วินเซนต์ไม่รู้ข่าวเลื่อนนัดและแผนของเขาไม่ต้องพึ่งการถ่วงเวลาของกิเดียน เขาตั้งใจเริ่มค้นจากห้องเจ้าของสำนวน แล้วตามผู้รับต่อหากกระเป๋าย้ายไปแล้ว คำให้การวินเซนต์และบันทึกงานสั้นเปิดให้ผู้เล่นรู้ชื่อผู้จ้าง เป้าหมายเอาสมุดคืน และขอบเขตงานที่เขาได้รับ ไม่เพิ่มฉากสอบสวนมารา

**ความจริงสำหรับผู้เขียน:** มาราไม่มีส่วนในแผนฆาตกรรมและไม่มีการติดต่อกับกิเดียนเกี่ยวกับงานนี้ วินเซนต์ไม่สามารถรับรองความสัมพันธ์ทั้งหมดของผู้จ้างได้ จึงไม่ให้เขาพูดข้อเท็จจริงหลังฉากนี้เป็นสิ่งที่ตนรู้

## 3. แฟ้ม A–D และเหตุที่แฟ้ม C สำคัญ

| แฟ้ม | เนื้อหาฉบับใหม่ | หน้าที่ต่อผู้เล่น |
|---|---|---|
| A | ลำดับเหตุเบลล์เวเธอร์และสำเนารายงานที่เคยเผยแพร่ | แสดงเรื่องที่ทางการเคยประกาศ |
| B | สำเนาโทรเลขเตือน สมุดต้นฉบับของนายสถานีที่มาราให้ยืม และทะเบียนรับส่งเอกสาร | แสดงว่ามีคำเตือน ใช้เทียบเลขเอกสาร/ผู้ส่ง และเป็นเหตุที่มาราต้องการกระเป๋าคืน |
| C | สำเนารับรองคำสั่งให้เดินรถต่อ และคำสั่งแยกโทรเลขกับคำให้การออกจากสำนวน | เป็นหลักฐานที่ระบุการกระทำของกิเดียนโดยตรง จึงถูกเลือกทำลาย |
| D | สารบัญเอกสารฉบับรวบรวมใหม่ ประวัติแหล่งที่มา และหนังสือนำส่งวันที่ 14 พฤศจิกายน 1938 | ยืนยันว่ามี C อยู่จริง หมายเลขใดหายไป และกำลังส่งหลักฐานให้ใคร |

หนังสือนำส่งระบุว่านรินทร์ เวลจะขึ้นรถที่ฮัลเบิร์ดเวลา **20:45** และให้ไปพบแคสเซียนที่ห้องพักตู้ 4 เพื่อรับสำนวน การเดินทางต่อเปิดโอกาสให้ตรวจและรับมอบเอกสารจนถึงปลายทาง

เศษที่เหลือจากแฟ้ม C ต้องอ่านได้มากกว่าตัวย่อ G.H.: มีเลขเอกสาร วันที่ และบางส่วนของคำสั่งให้นำโทรเลข/คำให้การออกจากชุดสอบสวน ผู้เล่นจึงนำเลขเอกสารไปเทียบสารบัญและทะเบียนในแฟ้มที่เหลือ เพื่อระบุผู้ลงนามว่าเป็นกิเดียนได้ ตัวย่อและสีหมึกเป็นข้อมูลประกอบ ไม่ใช่ตัวตัดสินเอกลักษณ์ลำพัง

กิเดียนทำลายเอกสารใน C ที่มัดการกระทำของตน และคิดว่าส่วนที่เหลืออ่านไม่ได้ แต่กระดาษบางส่วนพับซ้อนอยู่จึงเหลือข้อความให้ตรวจได้ เขาไม่รู้ว่าผู้เล่นจะนำเศษนั้นไปเชื่อมกับทะเบียนอีกชุด การเผามีเป้าหมายหยุดชุดสำนวนที่พร้อมส่งในคืนนี้ ไม่ใช่การรับประกันว่าไม่มีสำเนาอื่นเหลืออยู่ในโลก รายละเอียดที่เหลืออยู่ต้องเขียนไว้ตั้งแต่เอกสารต้นแบบ ไม่ให้ระบบสร้างข้อความสำคัญเพิ่มภายหลัง

## 4. เหตุการณ์ฆาตกรรมและหลักฐานในห้อง

### 4.1 การมาพบ

ก่อนถึงฮัลเบิร์ด กิเดียนเข้าพบแคสเซียนโดยอ้างว่าจะรับสำนวนกลับไปตรวจตามอำนาจหน้าที่ ทั้งคู่รู้จักกันจากคดีเก่า แคสเซียนจึงเปิดรับและยอมสนทนา แต่ยืนยันว่าจะส่งสำนวนตามนัด ไม่คืนแฟ้มให้กิเดียน

แคสเซียนขอให้กิเดียนรับทราบเป็นลายลักษณ์อักษรว่าคดีเก่ากำลังเข้าสู่การตรวจสอบ เขาเขียนสถานที่และเวลาการแจ้งต่อหน้าไว้ว่า “ห้องพักตู้ 4 — 14 พฤศจิกายน 1938 เวลา 20:15” กิเดียนประทับแหวนตราลงบนขี้ผึ้งในใบรับทราบ แสดงท่าทีว่าตนไม่มีเหตุให้กลัวเอกสารนั้น แล้วจึงกดดันให้เปลี่ยนผู้รับสำนวน เวลาในใบนี้เป็นบันทึกของแคสเซียน ต้องอ่านประกอบรอบส่งถ้วยเพิ่มและหลักฐานอีกสาย ไม่อ้างว่าเป็นเครื่องยืนยันเวลาอย่างอิสระ

เมื่อไม่ได้ผล กิเดียนพยายามแย่งแฟ้ม เกิดการต่อสู้ เขาคว้ามีดเปิดจดหมายบนโต๊ะมาแทงแคสเซียน เหตุทำร้ายถึงตายเกิดราว **20:25** นาฬิกาพกในเสื้อผู้ตายกระแทกเสียหายในการต่อสู้ กิเดียนเผาเอกสาร C แล้วพบกำหนดนัดนรินทร์ในหนังสือนำส่ง จึงไปดักพบผู้รับสำนวนที่ฮัลเบิร์ด

## 6. เหตุผลของการรอและคำโกหกที่ตรวจสอบได้

นรินทร์รู้จักกิเดียนในฐานะเจ้าหน้าที่อาวุโสจากหน่วยงานที่เกี่ยวข้อง กิเดียนทราบชื่อผู้รับ เลขสำนวน และสถานีขึ้นรถจากหนังสือนำส่ง การอ้างรายละเอียดจริงทำให้ข่าวเลื่อนนัดดูน่าเชื่อถือ นรินทร์จึงยอมรอถึง 21:30 โดยยังไม่ถือว่าขาดนัด

ใช้คำโกหกแบบเดียวตลอดเรื่อง:

> “พนักงานตู้เสบียงฝากผมมาบอกว่า คุณรีดขอเลื่อนรับแฟ้มเป็นสามทุ่มครึ่ง ระหว่างนี้รอที่เลานจ์กับผมก่อนก็ได้ครับ”

พนักงานตอบได้เฉพาะส่วนที่ตนรู้:

> “ผมไม่เคยรับคำสั่งเลื่อนนัด และไม่ได้ฝากคุณฮาร์ตมาบอกคุณครับ ตอนส่งชา คุณรีดบอกว่าถ้าคุณมาถามถึงเขา ให้พาไปได้ทันที”

สิ่งที่ถูกหักล้างโดยตรงคือคำอ้างว่า **พนักงานเป็นแหล่งข่าวและผู้มอบหมายให้กิเดียนส่งข่าว** ไม่ใช่การถือว่าคำสั่งตอน 20:10 ทำให้เปลี่ยนนัดภายหลังไม่ได้ ผู้เล่นเห็นคำกล่าวอ้างสองแหล่งขัดกัน และนำไปประเมินร่วมกับการเข้าถึงเอกสารและแรงจูงใจของกิเดียน คำปฏิเสธของพนักงานไม่ใช่เครื่องพิสูจน์ความจริงที่ไม่อาจผิดได้โดยลำพัง

พนักงานไม่ได้ตามหานรินทร์ก่อนพบศพ เพราะคำสั่งเดิมคือให้พามาพบเมื่อถูกถาม เขากำลังทำงานรับผู้โดยสารและตรวจตู้ตามปกติ กิเดียนเข้าถึงนรินทร์ก่อน จึงกันไม่ให้ผู้เล่นไปถามแหล่งข่าวจริง

หลังพบศพจึงใช้ประโยคสำคัญของกิเดียน:

> “คุณอยู่กับผมตลอดช่วงที่ไฟดับ คุณยืนยันให้ผมได้”

คำยืนยันนี้เป็นจริง การใช้มันแทนที่อยู่ช่วงก่อนขึ้นรถเป็นข้อสรุปที่ผิด กิเดียนไม่ได้จัดเหตุไฟดับไว้ล่วงหน้าและไม่ได้รู้ว่าวินเซนต์รับงานมา

## 8. ข้อสรุปที่หลักฐานรองรับ

### 8.1 เวลา: แยกสามคำถาม

1. **ไฟดับเมื่อไร:** บันทึกระบบระบุ 21:15–21:18 และนาฬิกาผนังหยุดเมื่อวงจรหลักขาด จึงไม่ใช่นาฬิกาเวลาตาย
2. **เหตุรุนแรงในห้องเกิดเมื่อไร:** นาฬิกาพกแตกที่ 20:25 ร่วมกับคำให้การเรื่องเสียงของกระแทกที่ผูกกับช่วงอุโมงค์ และสภาพห้อง รองรับเหตุช่วงประมาณ 20:20–20:26 เขม่าบนเลือดเป็นข้อมูลสนับสนุนลำดับ ไม่ใช่ตัวพิสูจน์เพียงชิ้นเดียว
3. **แพทย์ระบุเวลาเสียชีวิตได้ละเอียดแค่ไหน:** ในรุ่นนี้แพทย์ไม่ระบุเป็นนาที ไม่ใช้ความเย็นของร่างหรือข้อความ “ไม่น้อยกว่าหนึ่งชั่วโมง” เป็นเครื่องคำนวณเวลาตาย เธออธิบายสิ่งที่ตรวจพบและให้ผู้เล่นเทียบกับเหตุการณ์ในฉาก

**ความจริงผู้เขียน:** การทำร้ายและเสียชีวิตเกิดราว 20:25

**คำสรุปสำหรับผู้เล่น:** “หลักฐานร่วมกันชี้ว่าเหตุทำร้ายที่ห้องแคสเซียนเกิดก่อนเวลาไฟดับ และสอดคล้องกับช่วงที่ขบวนผ่านอุโมงค์ ไม่ใช่ช่วงที่กิเดียนนั่งอยู่กับนรินทร์”

การจับเวลาเสียงของตกกับนาฬิกาไม่ใช่การเห็นการฆ่า หลักฐานเวลาแสดงลำดับและทำให้ที่อยู่ตอนไฟดับไม่เพียงพอ ต้องใช้หลักฐานบุคคล แรงจูงใจ และพฤติกรรมประกอบการยื่นคดี ไม่เขียนว่าแพทย์หรือพนักงานเห็นเวลาตาย 20:25 ด้วยตนเอง

### 8.4 การตัดข้อสงสัยอีกสองคน

- **ลิโอรา:** สมุดอย่างเดียวเป็นบันทึกที่เธอเขียนเอง ต้องเทียบคำยืนยันผู้ป่วย ช่วง 20:10–20:45 ครอบคลุมเหตุที่อนุมานได้ แต่การมีเอกสารบิดาไม่ใช่เหตุล้างมลทินหรือกล่าวหาลำพัง
- **วินเซนต์:** ตั๋วเป็นทางนำไปหาข้อมูล สำเนารับรองจากสถานีที่ระบุว่าอยู่ต่อหน้าเจ้าหน้าที่ 20:10–20:35 และบันทึกรับขึ้นรถ 20:45 ใช้ประกอบกับช่วงเหตุได้ นี่เป็นข้อมูลที่ต้องเพิ่ม ไม่ได้มีในเกมแล้ว
- หากผู้เล่นยังไม่มีข้อมูลที่อยู่ของวินเซนต์ ข้อสรุปจากไฟดับต้องเป็นเพียง “การตัดไฟและคราบเลือดยังไม่รองรับว่าเป็นคนฆ่า” ไม่ประกาศว่าพิสูจน์ความบริสุทธิ์ครบแล้ว
- การล้างมลทินทั้งสองคนเป็นเส้นทางเพิ่มความมั่นใจและความเข้าใจเรื่อง ไม่บังคับเป็นงานสะสมเพิ่มเติมเมื่อผู้เล่นสร้างคดีกิเดียนครบตามสี่ประเด็นแล้ว

## 10. ฉากจบและเส้นตาย

- **ฉากจบแท้:** นรินทร์ยื่นคดีที่ประกอบเวลา แรงจูงใจ โอกาสเข้าถึง และการปกปิดได้ กิเดียนถูกควบคุมตัวเพื่อดำเนินคดีคืนนี้ และสำนวนเบลล์เวเธอร์เข้าสู่การตรวจสอบใหม่ การจับกุมคืนนี้ไม่เท่ากับมีคำพิพากษาคดีเก่าเสร็จทันที
- **ข้อมูลลิโอราเพิ่มเติม:** ถ้าผู้เล่นอ่านเอกสารบิดา ให้มีข้อความว่าคำให้การของเอเลียสกลับเข้าสู่สำนวน ไม่มีคำกล่าวว่าเอเลียสตายในเหตุชนหรือมีบุคคลลับถูกค้นพบ
- **คดีไม่ครบ:** ผู้เล่นเชื่อมกิเดียนกับแฟ้มได้แต่ยังอธิบายประเด็นอื่นไม่ครบ ผลต้องระบุช่องว่างจริงและไม่กล่าวถึงหลักฐานที่ไม่เคยพบ/ไม่เคยส่ง
- **กล่าวหาวินเซนต์ผิด:** แสดงความผิดจากการใช้เหตุไฟดับและการสัมผัสเลือดแทนการพิสูจน์ช่วงลงมือ หากผู้เล่นรู้ข้อมูลที่หักล้างข้อกล่าวหาแล้ว กฎต้องไม่ยอมให้ละข้อมูลนั้นเพื่อบังคับฉากจบผิด
- **กล่าวหาลิโอราผิด:** แสดงความผิดจากการตีความความลับเก่าและความลังเลเป็นการฆ่า แก้ข้อความปีเสียชีวิตของเอเลียสให้ตรงปี 1931
- **หมดเวลา:** รถถึงเวสต์มาร์ช คดีถูกโอนไปพร้อมสำนวนที่ยังไม่สมบูรณ์ อำนาจกำกับการสืบสวนของนรินทร์สิ้นสุดลงและผู้โดยสารแยกย้าย ไม่อ้างว่าคนร้ายหนีเพราะไม่มีกฎหมายจับกุมหลังถึงสถานี

คงเพดานเวลาเล่น 90 นาทีในช่วงสร้างและทดลอง ใช้เวลาเดินทางในเรื่อง 21:30–23:00 ให้ตรงกัน หากผลเล่นจริงนำไปสู่การเปลี่ยนเพดาน ต้องเปลี่ยนบทนำ/เวลาเทียบสถานีที่เกี่ยวข้องพร้อมกัน

## 11. สถานะของเนื้อหาเมื่อเทียบเกมปัจจุบัน

| ส่วน | การดำเนินการเมื่อเริ่มย้ายเข้าเกม |
|---|---|
| ชื่อและคำโปรย | ตัดคนที่แปดจาก story และชื่อหน้าเริ่ม/หัวเว็บ ใช้ Nocturne Express |
| บทนำ | เล่าเหตุขึ้นรถและข่าวเลื่อนนัดให้ผู้เล่นรู้ เปลี่ยนข้อความ “ถูกฆ่าท่ามกลางไฟดับ” เป็นความเชื่อของคนบนขบวน |
| `secret_file` และเอกสารลิโอรา | คงบทบาท/ID ที่กฎอ้างก่อน เปลี่ยนเป็นแฟ้มรักษาและคำให้การเอเลียสตาม A2 ไม่ลบวัตถุทิ้ง |
| แฟ้ม C/เศษไหม้/ตัวย่อ | เปลี่ยนจากเอกสารงบทั่วไปเป็นคำสั่งปกปิดที่เทียบเลขและผู้รับผิดชอบได้ |
| สมุดคดี `CASE_BACKGROUND` | เปลี่ยนข้อความแยกที่อยู่ใน API ให้ตรงเรื่องใหม่ เอกสารหน้าอ่านกับสมุดคดีต้องไม่เล่าคนละเรื่อง |
| พนักงานและคำให้การ | เพิ่มผู้คุยที่กล่าวหาไม่ได้และการเปิดข้อมูลตามประเด็น เป็นความสามารถที่ยังต้องพัฒนา |
| วินเซนต์ | คำสารภาพตรงเหตุไฟดับจริง เพิ่มข้อมูลผู้จ้างนอกฉากและหลักฐานสถานีตาม A2 |
| เวลา/ที่อยู่ | เลิกคำวินิจฉัยเวลาตายเป็นนาทีจากแพทย์ เพิ่มแหล่งข้อมูลรอบบริการ ปรับช่วงพยานลิโอราและข้อสรุปวินเซนต์ |
| กระดุม/ตรา/อาวุธ | ทำชนิดกระดุมให้สอดคล้อง รอยตราอยู่บนใบรับทราบคืนนี้ เพิ่มมีดเปิดจดหมายและคำบรรยายบาดแผลตามขอบเขต |
| เงื่อนไขจบและสี่เสา | ออกแบบตามหัวข้อ 8 ใน B แล้วเปลี่ยนกฎพร้อมข้อความฉากจบ ห้ามถือจำนวนขั้นต่ำเดิมเป็นข้อกำหนดใหม่ |
| เอกสารออกแบบเก่า | เก็บเป็นประวัติ ทำป้ายอ้างอิง A2 ก่อนเริ่มใช้เขียน ไม่ใช้ผู้โดยสารคนที่แปด/ยาพิษ/วันที่เก่ากลับมาเป็นข้อเท็จจริง |

ภาพตัวอย่างและเอกสารเดโมเก่าที่ผู้ใช้มีอยู่เดิมไม่ถูกแก้ในระยะนี้ ไฟล์เกม กฎ และหน้าเว็บยังคงเวอร์ชันเดิมจนถึงขั้นย้ายเนื้อหาตามแผน

## 12. สิ่งที่ปิดแล้วและสิ่งที่เป็นงานระยะ B

**ปิดใน A2:** ความผิดคดีเก่า, ปีและบทบาทเอเลียส, แรงจูงใจมารา/วินเซนต์, เหตุเข้าพบแคสเซียน, ที่มาข่าวเลื่อนนัด, วิธีฆ่าและอาวุธ, เหตุของรอยตราและกระดุม, หน้าต่าง/ไฟ/เขม่า, การพบศพ, ที่อยู่ตัวหลอก, แหล่งข้อมูลเวลา, เป้าหมายการยื่นคดี และผลของการถึงปลายทาง

**งาน B ที่ยังต้องทำ:** เขียนบทเต็มกับการ์ดปริศนา กำหนด ID หลักฐานใหม่และเงื่อนไขได้รับ คำนวณชุดหลักฐานขั้นต่ำทุกทาง ทำแผนผังการเปิดเผย/ด่าน/คำใบ้ และกำหนดข้อความ/เงื่อนไขฉากจบอย่างเป็นทางการ

ไม่มีคำถามเนื้อเรื่องที่ต้องให้ผู้ใช้เลือกเพิ่มก่อนเริ่ม B การทดสอบกับผู้เล่นจริงยังอาจทำให้ต้องปรับจังหวะและถ้อยคำ และ A2 ไม่ใช่หลักฐานว่าผู้เล่นจะเข้าใจหรือเล่นจบใน 15–25 นาทีแล้ว
