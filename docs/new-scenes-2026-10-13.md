# Nocturne Express — ฉากเล่าเรื่องเพิ่มเติม

วันที่13ตุลาคม2026

เพิ่มฉากสามช่วงใน `data/story.json` เพื่อให้ผู้เล่นได้สัมผัสเหตุการณ์ก่อนตีความ ทักท้วงตัวละครด้วยสิ่งที่ตนพิสูจน์แล้ว และเห็นภาพรวมจากคดีที่ยื่นจริงหลังจบ เรื่องและเงื่อนไขชนะเดิมยังเป็นฐาน ไม่เพิ่มหลักฐานหรือเสาบังคับใหม่

| ฉาก | จังหวะ | หน้าที่ |
|---|---|---|
|`boarding` — นัดที่คุณยังไปไม่ถึง|ก่อนเริ่มสอบสวน|5หน้า: ขึ้นรถ20:45 → ข่าวเลื่อนนัด → รอเลานจ์ → ไฟดับ → รับข่าวและเริ่มสืบ21:30|
|`gideon_confrontation` — คำยืนยันของคุณครอบคลุมเวลาใด|หัวข้อสนทนาที่เปิดหลังพิสูจน์|4หน้า: ผู้เล่นแยกเวลา → กิเดียนกดดันให้ยืนยันความทรงจำ → ผู้เล่นทักท้วงแหล่งข่าว → กิเดียนยังไม่รับสารภาพ|
|`case_reconstruction` — ต่อเหตุการณ์จากคดีที่คุณยื่น|หลัง `true_ending` เท่านั้น|6หน้าที่ปรากฏในชุดยื่นปกติ: ช่วงเหตุรุนแรง → เหตุผลแฟ้มC → สองสายเชื่อมบุคคล → ข่าวเลื่อนนัด → ขอบเขตพยานตอนไฟดับ → ส่งมอบคดี|

## บทนำ: ให้ผู้เล่นมีประสบการณ์ก่อนมีคำถาม

ฉากขึ้นรถไม่บอกว่ากิเดียนโกหกหรือว่าเหตุเกิดก่อนขึ้นรถ ผู้เล่นเห็นว่ากิเดียนรู้ชื่อกับสำนวนจึงตามไปรอ และเห็นว่าเขาอยู่ด้วยตอนไฟดับจริง ประโยค “คุณยืนยันให้ผมได้” เกิดหลังข่าวพบศพเท่านั้น

ฉากนี้เล่าความทรงจำเดิมที่เกมให้ตั้งแต่ต้น ไม่มอบเบาะแสเพิ่ม ไม่สร้างการเลือกหลอก ๆ ที่บอกว่าผู้เล่นเปลี่ยนอดีตได้ และไม่ใช้ภาพเกิดเหตุที่เปิดร่องรอยล่วงหน้า ข้อความ briefing ยังทำหน้าที่สรุปสำหรับอ่านทวนได้

## ฉากทักท้วง: ผู้เล่นต้องมีเหตุผลก่อนเผชิญหน้า

เพิ่มหัวข้อ `gideon_hart:confrontation` ป้าย “ทักท้วงพยานเรื่องสองเวลา” และ `scene_id: gideon_confrontation` เปิดเมื่อมีทั้ง:

- `claim_two_times` ที่ผู้เล่นเสนอพร้อมหลักฐานและผ่านการตรวจแล้ว
- `D16_POSTPONEMENT_LIE` จากความทรงจำข่าวเลื่อนนัดกับคำปฏิเสธของพนักงาน

ฉากอ้างเฉพาะข้อมูล7รายการของเส้นเวลาและ2รายการของข่าวเลื่อนนัด ไม่มีการกล่าวถึงอาวุธ แฟ้มC หรือสายส่วนตัวที่ผู้เล่นอาจยังไม่พบ กิเดียนแย้งว่าการแยกเวลาไม่ระบุตัวผู้ฆ่า ซึ่งยังถูกในขอบเขตของมัน ผู้เล่นต้องกลับไปประกอบคดีเอง

หัวข้อนี้เป็นทางเลือก ไม่มี `grants_evidence` เพิ่ม ไม่เปลี่ยนเงื่อนไข True Ending และไม่กล่าวหาแทนผู้เล่น `text` ของหัวข้อเก็บบทครบพร้อมเว้นย่อหน้า เพื่อให้ยังอ่านได้หากไม่ได้เปิดภาพเป็นหน้า

## ฉากสรุป: เห็นเฉพาะสิ่งที่ยื่นจริง

การสร้างฉากหลังจบใช้หลักฐานในชุดยื่น ไม่ใช้หลักฐานทั้งหมดที่เคยพบ ส่วนเชื่อมบุคคลมีหน้าทางเลือก3แบบ:

| หน้า | เงื่อนไข |
|---|---|
|`contact_button_wax`|`D05` + `D06` + `D07`|
|`contact_tea_button`|`D04` + `D05` + `D07`|
|`contact_tea_wax`|`D04` + `D06` + `D07`|

คดีขั้นต่ำ19/20/20รายการทำให้มีหน้าสายส่วนตัวตรงกับคู่ที่ยื่น1หน้า รวมเป็น6หน้า ไม่ต้องเพิ่มกลไกเลือกหน้าแบบพิเศษ หากเรียกตัวช่วยด้วยข้อมูลสังเคราะห์ที่มีครบทั้งสามสาย อาจผ่านหลายหน้าได้ แต่ชุดยื่นปกติภายใต้เพดาน20ไม่สามารถมีหลักฐานฐานและครบสามสายพร้อมกัน

ไม่เพิ่มหน้าหักล้างวินเซนต์หรือลิโอราในฉากนี้ เพราะชุดยื่นขั้นต่ำไม่มีที่พอเพิ่มเงื่อนไขที่อยู่ครบสองรายการ และจะทำให้เกิดหน้าที่เข้าถึงไม่ได้ตามกติกาปกติ หน้าไฟดับกล่าวเฉพาะเวลาระบบกับความทรงจำที่มีจริง ไม่เฉลยวินเซนต์เป็นผู้ตัดไฟโดยอาศัยความรู้ผู้เขียน

ฉากไม่แสดงภาพจำลองกิเดียนแทงด้วยอาวุธที่ไม่ได้อยู่ในคดีที่ยื่น ไม่ระบุเวลาตายแน่นอนที่20:25 และไม่ใช้คำรับสารภาพใหม่มายืนยันย้อนหลัง แต่ละหน้าระบุรายการ `evidence_ids` และเงื่อนไขที่ตรวจได้

## สัญญาข้อมูลและภาพ

`narrative_scenes` เป็น mapping ของ `{title, pages}` แต่ละหน้ามี `id`, `speaker`, `time_label`, `text`, `art` และอาจมี `evidence_ids`, `requires_evidence`, `requires_deductions`, `requires_claims` เงื่อนไขเป็นข้อมูลฝั่งดำเนินเกม ไม่ใช่สิ่งที่ต้องส่งให้ผู้เล่นเห็นเป็นสูตรเฉลย

ภาพใช้ ID ที่มีอยู่ใน `assets/nocturne-stylized-v2` เช่น `scene-04-corridor`, `scene-05-lounge`, `detail-pocket-watch`, `detail-dossier`, `detail-teacups`, `detail-wall-clock` ไม่สร้างภาพใหม่ หน้าสายกระดุมกับตราใช้ภาพทางเดินแทนภาพก้อนขี้ผึ้งเดิม เพราะข้อเท็จจริงปัจจุบันเป็นใบรับทราบที่มีตรา ส่วนหน้าส่งมอบใช้ภาพเลานจ์ทั่วไปเพื่อไม่เน้นแหวนในคดีที่ผู้เล่นยื่นเฉพาะชาและกระดุม รูปประกอบไม่ทำหน้าที่เพิ่มหลักฐานหรือยืนยันรายละเอียดที่ข้อความยังไม่ได้ให้

## เกณฑ์ตรวจส่งมอบ

1. บทนำอ่านย้อนหรือข้ามได้โดยไม่เพิ่มหลักฐานซ้ำหรือเปลี่ยนข้อเท็จจริง
2. ฉากทักท้วงไม่เปิดก่อนข้อสรุปและคำปฏิเสธต้นทางครบ การเรียกตรงต้องไม่ข้ามเงื่อนไข
3. ฉากทักท้วงจบแล้วเล่นต่อได้ ไม่ปิดคดีและไม่มอบหลักฐานใหม่
4. ฉากสรุปเปิดเฉพาะ True Ending และแต่ละคู่มีหน้าที่ตรงกับหลักฐานยื่นจริง ไม่อ้างสายที่ขาด
5. ข้อความและรายการอ้างอิงไม่เปิดข้อเท็จจริงของผู้เขียนที่ยังไม่อยู่ในคดีที่ยื่น

ฉากใหม่มีเป้าหมายเพิ่มความต่อเนื่องทางอารมณ์และช่วยทบทวนเหตุผล ยังไม่มีผลจากผู้เล่นจริงว่าทำให้เข้าใจหรือสนุกขึ้น หากต้องการวัดความเข้าใจจากการสืบสวนเอง ผู้ดำเนินการทดลองต้องหยุดถามก่อนผู้เล่นยืนยันส่งคำกล่าวหา เพราะข้อความฉากจบเดิมแสดงข้อสรุปทันทีหลังส่งคดี การถามหลังส่งแต่ก่อนเปิดฉากย้อนหลังจึงไม่ใช่การวัดก่อนเห็นเฉลย หน้าเว็บยังไม่มี study mode ที่พักผลคดีเพื่อรับคำตอบ

ทั้งสองกลุ่มทดลองต้องได้รับบทนำ สิทธิ์ข้าม เงื่อนไขเปิดฉากทักท้วง และเวลาอ่านอย่างเท่าเทียมกัน บทนำอ่านก่อนเริ่มนาฬิกาคดี ส่วนฉากทักท้วงอ่านระหว่างเวลาสืบสวนและอาจช่วยสอนหรือย้ำเหตุผล จึงต้องนับเป็นส่วนหนึ่งของประสบการณ์ที่ให้ผู้เล่น หลังจบแท้ผู้เล่นเลือกเปิดฉากย้อนหลังเองได้ หากเก็บความเข้าใจหลังอ่าน ให้รายงานแยกจากผลก่อนส่งคดี พร้อมบันทึกว่าได้ดูหรือข้ามฉาก

ชุดทดลองตัวตัดสินใน CLI ตรวจคำสั่งเปิดบทและสถานะ ไม่ครอบคลุมการเลือกหน้าภาพหรือการเปิดอ่านย้อนหลังบนเว็บ รายละเอียดวิธีเก็บข้อมูลและข้อจำกัดอยู่ใน [protocol การทดลอง](research-protocol-2026-10-12.md)

## ผลตรวจการนำเข้าเกม

วันที่13ตุลาคม2026: Python offline237ข้อผ่าน (ข้าม5ข้อที่เรียกLLM), Frontend Node37ข้อผ่าน และชุดพัฒนา symbolic58/58ตาผ่านโดยไม่เรียกprovider กรณีฉากย้อนหลังทั้งสามคู่ผ่าน API พร้อมทดสอบว่าการส่งสถานะปลอมไม่เปิดฉากและข้อความอ้างเฉพาะหลักฐานที่ยื่น

ทดสอบ Edge ผ่านหน้าเกม40คำสั่งจนจบแท้ ตรวจบทนำ5หน้า ฉากทักท้วง4หน้า และฉากย้อนหลัง6หน้าของคู่กระดุมกับตรา ไม่มีJavaScript error ตรวจจอ1440×1000และ390×844 ข้อความฉากขนาด18px ไม่ล้นแนวนอน และเลื่อนอ่านข้อความบนมือถือได้ครบเหนือแถบปุ่ม ผลกับภาพอยู่ใน `tmp/browser-story-check/` ซึ่งเป็นไฟล์ตรวจในเครื่อง

ผู้เล่นเห็นประเด็นสนทนาใหม่ในสมุดคดีแท็บ “ประเด็นค้าง” หลังเงื่อนไขครบ และเปิดฉากย้อนหลังด้วยปุ่ม “ดูเหตุการณ์ย้อนหลัง” หลังฉากจบแท้ ระหว่างอ่านฉากทักท้วงนาฬิกายังเดิน หากหมดเวลาระบบปิดฉากและยกเลิกคำสั่งที่รออยู่
