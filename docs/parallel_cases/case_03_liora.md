# Case 03 — ยาและรอยแค้น

ลิโอราพบเอกสารว่าแคสเซียนรับประโยชน์จากการปิดคดีและส่งพ่อเข้าสถานบำบัด เธอตั้งใจแก้แค้น ก่อน 20:00 กิเดียนเข้าพบแคสเซียนและเผาสำเนาคำสั่ง แล้วไปอยู่ตู้เสบียงถึง 20:30 มีพนักงานกับผู้ป่วยเห็นเขา

20:10 ลิโอรานำถาดให้แคสเซียนที่ยังมีชีวิต เธอใช้ยา L-7 ซึ่งฉลากห้ามรับประทาน แคสเซียนล้มช่วงอุโมงค์ 20:20–20:26 นาฬิกาหยุด 20:25 ลิโอราแทงอำพรางหลังเขาล้ม ทิ้งถ้วยผู้ตายและเศษห่อยาไว้ในห้อง เก็บขวดกลับตู้ยา แล้วไปดูแลผู้ป่วย 20:30–20:45 แต่ลงสมุดและอ้างว่าเริ่มดูแล 20:10

วินเซนต์มีพยานสถานี 20:10–20:35 และขึ้นรถ 20:45 ก่อนตัดไฟและเข้าไปสัมผัสร่างช่วง 21:15–21:18 พนักงานพบศพ 21:20 ลิโอราอ้างว่าเป็นแผลแทงช่วงไฟดับ คำวินิจฉัยนี้เป็นคำให้การของผู้ต้องสงสัย ไม่ใช่ข้อเท็จจริงที่ระบบรับรอง

หลักฐานต้องเชื่อมห่อยา L-7 กับรอยฉีกต้นขั้วในสมุด เลขชุดขวด ปริมาณยา และลายเซ็นผู้เบิก พยานผู้ป่วยหักล้างเวลาเริ่มดูแล ต้องตรวจที่อยู่กิเดียนในช่วงอุโมงค์แทนการนำพยานไฟดับมาใช้ย้อนหลัง ร่องรอยศพไม่สามารถบอกชนิดพิษหรือเวลาตายเป็นนาที ต้องเก็บตัวอย่างตรวจยืนยันหลังส่งมอบคดี

  หลักฐาน: pocket_watch, cassian_reed, second_teacup, staff_service_record, staff_impact_testimony; ข้อสรุปก่อนหน้า: ไม่มี

  หลักฐาน: staff_service_record, liora_patient_witness, gideon_no_early_alibi; ข้อสรุปก่อนหน้า: D01_POISON_DEATH_WINDOW

## ฉากจบ

### ยาพิษและหยดน้ำตา

ห่อยาที่ต่อกับต้นขั้ว ขวด L-7 และทะเบียนเบิกยาของลิโอราเชื่อมถ้วยผู้ตายกับห้องแพทย์ พยานหักล้างเวลาที่เธออ้าง ขณะที่ตรวจที่อยู่คนอื่นได้ เมื่อเผชิญหลักฐานร่วมกัน ลิโอรายอมรับว่าให้ยาผิดวัตถุประสงค์แล้วแทงอำพรางหลังแคสเซียนล้ม นรินทร์ส่งตัวและเก็บตัวอย่างให้ตรวจพิษกับสาเหตุการตายอย่างเป็นทางการ พร้อมส่งคดีเอเลียสให้สอบสวนใหม่

### แพะรับบาปในความมืด

คุณกล่าวหาวินเซนต์จากการตัดไฟและคราบเลือดโดยยังไม่ตรวจที่อยู่ก่อนขึ้นรถ การสืบสวนบนขบวนปิดลงด้วยข้อกล่าวหาที่ผิด ลิโอรายังไม่ถูกเชื่อมกับการนำยาเข้าห้อง ต้องให้เจ้าหน้าที่ปลายทางตรวจพยานและสาเหตุการตายต่อ ไม่ใช่คำพิพากษาทันที

### คำสั่งการเมือง

คุณใช้การเผาสำเนาคดีเก่าเป็นเหตุฟันธงว่ากิเดียนฆ่าแคสเซียน แต่ยังไม่ได้เชื่อมเขากับการลงมือในช่วงอุโมงค์ คำกล่าวหาที่รีบร้อนทำให้การสืบสวนบนขบวนสิ้นสุดลงโดยไม่ได้ตรวจเส้นทางยาและที่อยู่ของทุกคนครบถ้วน

### คำกล่าวหาที่พิสูจน์ไม่ได้

คำกล่าวหายังไม่มีหลักฐานเชื่อมครบ คุณส่งสิ่งที่ตรวจพบต่อให้เจ้าหน้าที่เวสต์มาร์ชพร้อมระบุประเด็นที่ยังไม่ทราบ การสอบสวนต่อจากนี้อยู่นอกช่วงเวลาที่คุณควบคุมได้

### ถึงเวสต์มาร์ช

เวลา 23:00 รถเข้าเวสต์มาร์ช เจ้าหน้าที่ปลายทางรับคดีและควบคุมการสอบสวนต่อ คุณส่งสมุดคดีพร้อมสิ่งที่ค้นพบ การสืบสวนช่วงบนรถสิ้นสุดลงทั้งที่คุณยังไม่ได้เชื่อมข้อกล่าวหาให้ครบ
