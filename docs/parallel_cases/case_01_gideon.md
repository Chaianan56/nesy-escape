# Case 01 — แฟ้มลับและเถ้าถ่าน

กิเดียนต้องการทำลายแฟ้ม C ซึ่งเชื่อมตนกับคำสั่งเดินรถและการตัดข้อมูลออกจากสำนวนเบลล์เวเธอร์ปี 1923 เอเลียสรอดชีวิตและให้การเรื่องคำเตือนที่ถูกละเลย ต่อมาเสียชีวิตด้วยโรคประจำตัวในปี 1931 ไม่มีปมผู้โดยสารคนที่แปดในเรื่องฉบับนี้

20:10 พนักงานเห็นแคสเซียนมีชีวิต กิเดียนเข้าพบก่อนผ่านอุโมงค์ เกิดการต่อสู้ช่วง 20:20–20:26 และนาฬิกาหยุด 20:25 เขาเผาแฟ้ม C แล้วออกจากห้อง ประตูห้องเกิดเหตุไม่ได้ล็อก จึงเป็นคดีที่ต้องพิสูจน์ผู้เข้าออก ไม่ใช่ห้องปิดตาย

20:45 นรินทร์ขึ้นรถ กิเดียนแต่งข่าวเลื่อนนัดเพื่อรั้งเขาไว้ วินเซนต์ตัดไฟ 21:15–21:18 เพื่อขโมยกระเป๋า กิเดียนฉวยโอกาสใช้การอยู่กับนรินทร์สร้างพยานที่ครอบคลุมเพียงช่วงไฟดับ เขาไม่ได้วางแผนการตัดไฟกับวินเซนต์ พนักงานพบศพ 21:20

ต้องเชื่อมเวลา แรงจูงใจ หลักฐานการมาพบอย่างน้อยสองสาย และตรวจต้นทางข่าวเลื่อนนัด พร้อมเสนอ claim_two_times โดยแนบหลักฐาน พยานผู้ป่วยและใบรับรองสถานีช่วยตรวจที่อยู่ลิโอราและวินเซนต์ระหว่างเหตุในอุโมงค์

## ฉากจบ

### ความจริงที่มาถึงก่อนความมืด

คุณไม่ได้จำผิด กิเดียนอยู่กับคุณตอนไฟดับจริง แต่เหตุรุนแรงเกิดก่อนคุณขึ้นรถ
หลักฐานที่คุณรวบรวมเชื่อมช่วงเหตุ การมาพบที่เขาปฏิเสธ แฟ้มที่เปิดความรับผิดในคดีเก่า และต้นทางข่าวเลื่อนนัดที่ไม่เป็นจริงเข้าด้วยกัน
กิเดียนใช้ความเชื่อใจให้คุณรอ แล้วฉวยโอกาสจากไฟดับที่เขาไม่ได้วางแผน เปลี่ยนคุณให้เกือบเป็นพยานแก้ตัวในช่วงเวลาที่ไม่เกี่ยว
ที่เวสต์มาร์ช คุณส่งมอบตัวกิเดียนพร้อมหลักฐานและข้อจำกัดของแต่ละชิ้นให้เจ้าหน้าที่ คดีเบลล์เวเธอร์กลับเข้าสู่การตรวจสอบ การดำเนินคดีต่อไปยังต้องผ่านการตรวจหลักฐาน แต่คืนนี้ไม่มีใครถูกเลือกเป็นแพะเพื่อปิดเรื่องอย่างสะดวก

### พบแรงจูงใจ แต่ยังเชื่อมคดีไม่ครบ

ชุดเอกสารที่คุณรวบรวมเชื่อมกิเดียนกับสิ่งที่ถูกปกปิดในคดีเก่า แต่การรู้ว่าใครเสียประโยชน์ยังไม่เท่ากับพิสูจน์ว่าใครลงมือคืนนี้
ข้อกล่าวหาปิดลงพร้อมประเด็นที่ยังเชื่อมไม่ครบตามรายการข้างต้น คุณส่งสำนวนที่มีข้อจำกัดนี้ต่อให้เจ้าหน้าที่ปลายทาง

### แพะรับบาปในความมืด

วินเซนต์ตัดไฟและสัมผัสเลือดจริง คุณนำความผิดสองเรื่องนั้นไปสรุปว่าเขาเป็นผู้ฆ่าโดยยังไม่มีสายหลักฐานเชื่อมการลงมือ
วินเซนต์รับสารภาพเรื่องตัดไฟและขโมย แต่ปฏิเสธข้อหาฆาตกรรม ขณะที่กิเดียนพ้นจากข้อกล่าวหาครั้งนี้ การปิดคดีอย่างรวดเร็วซ้ำรอยการตัดข้อมูลในอดีต

### ความลับที่ถูกใช้แทนหลักฐาน

คุณนำความลับเรื่องครอบครัวและความไม่ไว้ใจแคสเซียนไปใช้แทนหลักฐานการลงมือ
แฟ้มที่ลิโอราปกป้องคือคำให้การของพ่อ ผู้รอดชีวิตจากปี 1923 และเสียชีวิตด้วยโรคประจำตัวในปี 1931 การที่เธอต้องการรื้อคดีไม่ได้พิสูจน์ว่าเธอฆ่าคนที่กำลังจะส่งสำนวนใหม่
ข้อกล่าวหาครั้งนี้ทำให้เสียงของเอเลียสถูกความระแวงกลบอีกครั้ง

### คำกล่าวหาที่พิสูจน์ไม่ได้

คำกล่าวหายังไม่มีหลักฐานเชื่อมครบ คุณส่งสิ่งที่ตรวจพบต่อให้เจ้าหน้าที่เวสต์มาร์ชพร้อมระบุประเด็นที่ยังไม่ทราบ การสอบสวนต่อจากนี้อยู่นอกช่วงเวลาที่คุณควบคุมได้

### ถึงเวสต์มาร์ช

เวลา 23:00 รถเข้าเวสต์มาร์ช เจ้าหน้าที่ปลายทางรับคดีและควบคุมการสอบสวนต่อ คุณส่งสมุดคดีพร้อมสิ่งที่ค้นพบ การสืบสวนช่วงบนรถสิ้นสุดลงทั้งที่คุณยังไม่ได้เชื่อมข้อกล่าวหาให้ครบ
