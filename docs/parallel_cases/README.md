# 🚂 ระบบคดีคู่ขนาน (Parallel Cases System Overview)
## สถาปัตยกรรมการสุ่มคดีและสารบัญเส้นทางเนื้อเรื่อง (Nocturne Express 1938)

> **สำหรับทีมพัฒนาและ AI Agents**  
> เอกสารฉบับนี้อธิบายโครงสร้างระบบ **Parallel Cases** สำหรับการสุ่มคดี (Case Randomization) เมื่อเริ่มเล่นเกมใหม่บนขบวนรถไฟ *Nocturne Express* โดยคงฉาก สถานที่ และตัวละครชุดเดียวกัน แต่เปลี่ยนตัวฆาตกร แรงจูงใจ ลำดับเวลาเกิดเหตุ และสายหลักฐานในแต่ละรอบ

---

## 🎲 ทำไมต้องมี Parallel Cases? (Design Purpose)

ในเกมสืบสวนทั่วไป เมื่อผู้เล่นเล่นจบ 1 รอบและรู้ว่าใครคือฆาตกร ตัวเกมจะหมดคุณค่าในการเล่นซ้ำ (Replayability)  
โปรเจกต์ **Nocturne Express** จึงถูกออกแบบด้วยแนวคิด **Parallel Cases (คดีคู่ขนาน)** โดยกำหนดให้ผู้ต้องสงสัยหลักทั้ง 3 คนบนรถไฟมีแรงจูงใจเบื้องลึกและโอกาสลงมือสังหารแคสเซียน รีด (Cassian Reed) ได้ทั้งสิ้น ขึ้นอยู่กับว่ารอบการเล่นนั้นระบบสุ่มเลือก **เส้นเรื่องใด (Case Route)** เป็นความจริงของเกม:

1. **ฉากและตัวละครคงที่ (Fixed Stage & Cast):** ขบวนรถไฟ 6 ตู้, เวลาเล่น 90 นาที, ผู้โดยสารและพนักงานชุดเดิม ทำให้ประหยัดทรัพยากรด้านโมเดลและ UI
2. **ตรรกะแบบสับเปลี่ยนได้ (Swappable Logic Graph):** Symbolic Engine สามารถโหลดไฟล์เนื้อเรื่องประจำคดี (`story_case_01.json`, `story_case_02.json`, `story_case_03.json`) เข้าสู่ Engine เมื่อเริ่มเกมใหม่
3. **การอ่านและพัฒนาที่ง่ายดาย (Modularity):** แต่ละคดีมีไฟล์เนื้อเรื่องเฉพาะของตัวเอง เขียนในรูปแบบนิยายสืบสวนที่มนุษย์อ่านสนุก และ AI อ่านเพื่อสกัดเป็น JSON Data ได้ทันที

## 📁 สารบัญไฟล์เนื้อเรื่องประจำคดี (Case Files Index)

คลิกเปิดอ่านเนื้อเรื่องของแต่ละเส้นทางได้ตามลิงก์ด้านล่าง:

1. **[Case 01: แฟ้มลับและเถ้าถ่าน (The Burnt Dossier — Gideon Hart)](case_01_gideon.md)**  
   *เส้นทางคดีหลักของเกมในปัจจุบัน:* กิเดียนสังหารแคสเซียนเพื่อเผาทำลายแฟ้ม C ก่อนรถไฟถึงสถานีฮัลเบิร์ด แล้วใช้ความมืดตอนไฟดับฝังภาพจำ Alibi หลอกตานรินทร์
2. **[Case 02: คมมีดในความมืด (The Strike in the Dark — Vincent Gray)](case_02_vincent.md)**  
   *เส้นทางนักสืบสายโจรกรรม:* วินเซนต์ตัดไฟเพื่อเข้าขโมยกระเป๋าเอกสาร เกิดการปะทะกับแคสเซียนในความมืดจนพลั้งมือสังหาร แล้วแกล้งทำเป็นโจรที่บังเอิญเจอศพ
3. **[Case 03: ยาพิษและรอยแค้น (The Doctor's Retribution — Dr. Liora Venn)](case_03_liora.md)**  
   *เส้นทางความแค้นของลูกสาว:* ลิโอราแอบวางยาพิษในชาร้อนของแคสเซียนตั้งแต่ก่อนถึงสถานีฮัลเบิร์ด แล้วใช้มีดแทงอำพรางศพ พร้อมบิดเบือนรายงานชันสูตรในฐานะแพทย์ประจำขบวน

## 🛠️ กลไกการทำงานของ Randomizer ในอนาคต

เมื่อผู้เล่นกด **"เริ่มคดีใหม่ (New Game)"**:
```python
# ตัวอย่าง Logic ใน backend (app/main.py หรือ game_setup.py)
AVAILABLE_CASES = ["case_01_gideon", "case_02_vincent", "case_03_liora"]

def setup_random_case():
    selected_case = random.choice(AVAILABLE_CASES)
    world_data = load_case_json(f"data/cases/{selected_case}.json")
    return new_game_state(world_data)
```
* **ประโยชน์:** ผู้เล่นไม่สามารถจำคำตอบเดิมมาตอบได้ ต้องเดินสำรวจ ตรวจนาฬิกา รอยเลือด สารเคมี และพยานในรอบนั้นๆ จริงๆ
* **สำหรับ AI:** AI สามารถอ่านไฟล์ `case_XX.md` เพื่อนำไปเจนเนอเรตไฟล์ JSON สำหรับคดีนั้นๆ หรือใช้เป็นฐานข้อมูลในการแต่งบทพูดของตัวละครให้ตรงกับคดีที่กำลังเล่นอยู่
