# คดีคู่ขนาน — Nocturne Express

ทั้งสามคดีเป็นความจริงคนละเส้นทาง ใช้ตัวละครและขบวนรถเดียวกัน แต่ต้องโหลดหลักฐาน บทสนทนา และกฎจากไฟล์ของคดีนั้นร่วมกัน

| คดี | ผู้ลงมือ | เหตุหลัก | พยานสำคัญ |
|---|---|---|---|
| [01 — กิเดียน](case_01_gideon.md) | กิเดียน | ทำร้ายแคสเซียนช่วงอุโมงค์ 20:20–20:26 นาฬิกาหยุด 20:25 | พนักงานได้ยินเสียงกระแทก; พยานไฟดับไม่ครอบคลุมช่วงนี้ |
| [02 — วินเซนต์](case_02_vincent.md) | วินเซนต์ | ต่อสู้ช่วงไฟดับ 21:15–21:18 | พนักงานเห็นผู้ตายมีชีวิต 21:14 และได้ยินเสียงต่อสู้ภายหลัง |
| [03 — ลิโอรา](case_03_liora.md) | ลิโอรา | นำยาผิดวัตถุประสงค์ให้ผู้ตายก่อนล้มช่วงอุโมงค์ แล้วแทงอำพราง | พนักงานเห็นถาดยา; ผู้ป่วยหักล้างเวลาเริ่มดูแล |

ทุกคดีไฟกลับ 21:18 พบศพ 21:20 เริ่มสอบสวน 21:30 และถึงเวสต์มาร์ช 23:00 นาฬิกาพกบอกเวลาที่กลไกหยุด ไม่ได้ยืนยันเวลาตายด้วยตัวเอง การสรุปบนรถเป็นสำนวนส่งสอบสวนต่อ ไม่แทนผลตรวจพิษหรือการพิพากษา

ระบบสุ่มทำงานแล้วใน `app/cases.py` โดยใช้ `data/cases/case_01_gideon.json`, `case_02_vincent.json`, `case_03_liora.json` และไม่สุ่มซ้ำคดีเดิมเมื่อเริ่มใหม่พร้อมคำสั่งสุ่ม

เส้นทางตรวจซ้ำ: `data/walkthrough.json`, `data/walkthrough_case_02.json`, `data/walkthrough_case_03.json` ทุกเส้นทางต้องเก็บหลักฐานด้วยคำสั่งปกติและผ่านประตูที่ล็อก ไม่เติมหลักฐานเพื่อข้ามการเล่น

เอกสารนี้มีเฉลยสำหรับผู้พัฒนา ไทม์ไลน์ผู้เล่นแสดงเฉพาะข้อมูลที่พบและคำให้การที่ได้รับ ส่วนข้อสรุปของกฎแสดงหลังปิดคดี
