# Case 02 — คมมีดในความมืด

วินเซนต์รับจ้างมาราชิงเอกสาร เขาขึ้นรถที่ฮัลเบิร์ด 20:45 และตัดไฟ 21:15 เพื่อเข้าห้องแคสเซียน ประตูไม่ได้ลงกลอน เกิดการต่อสู้และแย่งมีดในช่วงไฟดับ เขาหนีไปตู้ 6 เพราะกระเป๋าคล้องโซ่กับโต๊ะและเปิดรหัสไม่ได้ จึงยกทั้งใบหนีไม่ได้

กิเดียนพบแคสเซียน 20:15–20:30 และเผาสำเนาคำสั่ง ต้นฉบับแฟ้ม C ยังอยู่ในกระเป๋า เขาโกหกเรื่องข่าวเลื่อนนัดเพื่อชะลอการส่งมอบ แต่ไม่ได้ลงมือฆ่า นาฬิกาพกตกเสีย 20:25 พนักงานยังพูดกับแคสเซียนหลังเสียงของตก และเห็นเขามีชีวิตอีกครั้ง 21:14 ก่อนเสียงต่อสู้ช่วงไฟดับ พบศพ 21:20

ลิโอราดูแลผู้ป่วย 21:00–21:20 มีสมุดและพยานยืนยัน กิเดียนอยู่กับผู้เล่นช่วงไฟดับ ต้องพิสูจน์ช่วงเหตุเสียก่อนจึงใช้พยานที่อยู่ทั้งสองคนได้

คราบเลือดอย่างเดียวไม่ระบุตัวผู้แทง ต้องเทียบรอยต่อสู้ เส้นใยที่มือผู้ตายและด้ามมีด รอยฉีกโค้ต และคำอ้างว่าเพียงแตะศพ แรงจูงใจต้องมีบันทึกจ้างงานกับคำให้การเรื่องงาน ไม่ใช้เพียงการตัดไฟสรุปฆาตกรรม

## ฉากจบ

### แสงสว่างหลังความมืด

คำให้การว่าเพียงแตะศพไม่อธิบายเส้นใยในมือผู้ตาย รอยฉีกโค้ต และเสียงต่อสู้หลังพยานเห็นแคสเซียนยังมีชีวิต เมื่อประกอบกับการตัดไฟและงานชิงเอกสาร วินเซนต์ยอมรับว่าเกิดการต่อสู้และแย่งมีดแทง นรินทร์ส่งตัวพร้อมหลักฐานให้เจ้าหน้าที่ปลายทางตรวจยืนยัน ส่วนกิเดียนต้องรับการสอบสวนเรื่องทำลายสำเนาและคดีปี 1923 แยกต่างหาก

### หลงกลปมเก่า

คุณกล่าวหากิเดียน ฮาร์ต แต่กิเดียนมีพยานที่อยู่อันหนักแน่น—ตัวคุณเองที่นั่งดื่มกาแฟอยู่กับเขาตลอดช่วงเวลาไฟดับ 21:15–21:18 น. ข้อกล่าวหาตกไป กิเดียนฟ้องกลับฐานละเมิดอำนาจหน้าที่ ส่วนวินเซนต์ฉวยโอกาสหลบหนีไปในความมืด

### กับดักความระแวง

คุณกล่าวหา พญ. ลิโอรา เวนน์ แต่พยานผู้ป่วยในตู้ 3 ยืนยันว่าลิโอราอยู่ดูแลเขาตลอดช่วงไฟดับ ข้อกล่าวหาล้มเหลว

### คำกล่าวหาที่พิสูจน์ไม่ได้

คำกล่าวหายังไม่มีหลักฐานเชื่อมครบ คุณส่งสิ่งที่ตรวจพบต่อให้เจ้าหน้าที่เวสต์มาร์ชพร้อมระบุประเด็นที่ยังไม่ทราบ การสอบสวนต่อจากนี้อยู่นอกช่วงเวลาที่คุณควบคุมได้

### ถึงเวสต์มาร์ช

เวลา 23:00 รถเข้าเวสต์มาร์ช เจ้าหน้าที่ปลายทางรับคดีและควบคุมการสอบสวนต่อ คุณส่งสมุดคดีพร้อมสิ่งที่ค้นพบ การสืบสวนช่วงบนรถสิ้นสุดลงทั้งที่คุณยังไม่ได้เชื่อมข้อกล่าวหาให้ครบ
